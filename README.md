# 💬 Real-Time Chat App

A responsive frontend-only chat application built with HTML, CSS, and JavaScript.

## ✨ Features

- 💬 Chat input field and Send button
- ⚡ Messages appear instantly
- 📨 Different styles for sent and received messages
- 💾 LocalStorage to persist messages after page refresh
- 🕐 Timestamps for messages
- 🤖 Simple chatbot with predefined responses
- 🧹 Clear Chat functionality
- 🎨 Smooth message animations
- 📜 Smooth scrolling
- 📱 Responsive design for mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM Manipulation
